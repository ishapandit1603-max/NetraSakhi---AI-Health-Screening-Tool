# 🩺 **NetraSakhi — AI-Powered Rural Health Screening**

> **An AI-powered health screening tool combining Computer Vision and CNN-based classification to support preliminary disease and deficiency detection for rural healthcare.**

## 🔬 **Project Overview**

**NetraSakhi** uses **Hough Transform, Canny Edge Detection, and Contour Analysis** along with **CNN-based classification** to assist in screening for selected diseases and nutritional deficiencies.

The application also supports **vaccine and polio-drop date prediction**, enabling healthcare workers such as **ASHA workers** to assist with organized mass health screenings in rural communities.

## ✨ **Key Features**

- 🩸 **Anaemia Detection**
- 🦠 **Chickenpox Classification**
- 🍄 **Ringworm Classification**
- 💅 **Leukonychia (Zinc Deficiency) Detection**
- 👁️ **Computer Vision-Based Image Analysis**
- 🧠 **CNN Disease & Deficiency Classification**
- 💉 **Vaccine & Polio-Drop Date Prediction**
- 👩‍⚕️ **ASHA Worker Support for Mass Screening**
- 🌾 **Rural Healthcare Focus**

## 🛠️ **Tech Stack**

**Programming:** Python  
**Computer Vision:** OpenCV • Canny Edge Detection • Hough Transform • Contour Analysis  
**Deep Learning:** TensorFlow • Keras • CNN  
**Data Processing:** NumPy • Pandas  
**Application:** Flask  
**Visualization:** Matplotlib • Power BI

## ⚙️ **Workflow**

**Image Input** 📷 → **Preprocessing** 🖼️ → **Edge & Contour Analysis** 🔍 → **CNN Classification** 🧠 → **Screening Result** 📋 → **Vaccine Prediction** 💉

## 🎯 **Objective**

To develop an **AI-assisted rural healthcare screening solution** that enables faster preliminary identification of diseases and deficiencies while supporting **ASHA-led mass screenings and preventive healthcare tracking**.

> ⚠️ **Note:** The system is intended for preliminary screening support and does not replace professional medical diagnosis.
